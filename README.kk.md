# Академиялық нормобақылау · Қазақша

Қазақстан Республикасы Президентінің жанындағы Мемлекеттік басқару академиясының
талаптарына сай магистрлік жұмыстарды PDF форматында автоматты тексеру платформасы.

0.2.0 нұсқасы: apa.kz сайтындағы түпнұсқа логотип пен дәл фирмалық түстер,
жаңартылған басты бет, жеке кабинет және PDF жүктеу формасы. PDF құжаты мен
есепті бір экранда көруге және ескерту көрсетілген бетке өтуге болады.

1. Windows ZIP мұрағатын жазуға рұқсаты бар бумаға шығарыңыз.
2. `APA Thesis Checker.exe` іске қосыңыз. Браузерде `127.0.0.1:8765` ашылады.
3. Тіркеліңіз. Алғашқы жергілікті пайдаланушы әкімші болады.
4. «Жаңа тексеру» бөлімінде PDF, жұмыс тілі мен оқу ұзақтығын таңдаңыз.
5. Есеп дайын болғанда оны PDF немесе JSON түрінде жүктеңіз. Тарих жеке кабинетте сақталады.

Интерфейс пен есептер қазақ, орыс және ағылшын тілдерінде қолжетімді.
Интерфейс тілін өзгерту жұмыс тілін өзгертпейді. Түпнұсқа өзгертілмейді.
Windows нұсқасы жергілікті жұмыс істейді; интернет арқылы кіру қосылмаған.
Тоқтату: Ctrl+C немесе қолданба терезесін жабу.
Құжаттар мен тіркелгілер EXE жанындағы `data/` бумасында сақталады.

Барлық іске асырылған тексерулер автоматты. «Деректер жеткіліксіз» нәтижесі
PDF қасиеттері сенімді қорытынды жасауға жетпейтінін білдіреді; ол сәйкестік емес.
Өрістер мен интервал PDF орналасуы бойынша бағаланады. Плагиат, зерттеу сапасы,
орфография және OCR тексерілмейді. Шектеу: мәтіндік PDF, 30 МБ, 300 бет.

Талаптар көзі — 13.09.2024 жылғы № 586 бұйрықтың 1-қосымшасы.
1 жылдық бағдарлама: кемінде 40 бет; 1,5 және 2 жыл: кемінде 60 бет, қосымшасыз.
Әкімші профильді `/admin/` арқылы өзгерте алады. Өзгерістер жаңа тексерулерге қолданылады.
Есеп қорғауға жіберу туралы ресми шешім емес.

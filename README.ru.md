# Академический нормконтроль · Русский

Платформа для проверки PDF магистерских работ по требованиям Академии
государственного управления при Президенте Республики Казахстан.

1. Распакуйте Windows ZIP в доступную для записи папку.
2. Запустите `APA Thesis Checker.exe`; откроется браузер на `127.0.0.1:8765`.
3. Создайте аккаунт. Первый локальный пользователь — администратор.
4. Выберите «Новая проверка», загрузите PDF, укажите язык и длительность программы.
5. Дождитесь отчёта; скачайте PDF или JSON. Работы доступны в истории.

Интерфейс, сообщения и отчёты доступны на казахском, русском и английском.
Смена языка интерфейса не меняет язык загруженной работы. Документ не изменяется.
Запуск полностью локальный. Внешний доступ по интернету в Windows-сборке не включён.
Чтобы остановить сервер и обработчик, нажмите Ctrl+C или закройте окно приложения.
Данные хранятся рядом с EXE в `data/`; не удаляйте папку для сохранения истории.

Все реализованные проверки автоматические. «Недостаточно данных» означает,
что свойства PDF не позволяют установить результат; это не успешная проверка.
Границы полей и интервал измеряются по вёрстке, а не параметрам исходного Word.
Не проверяются плагиат, качество исследования и орфография. OCR отсутствует.
Поддерживаются текстовые PDF до 30 МБ и 300 страниц.

Источник правил: приложение 1 к приказу от 13.09.2024 № 586, ссылка в разделе
«Руководство». Для годичного обучения — минимум 40 страниц, для 1,5 и 2 лет — 60,
без приложений. Профиль параметров доступен администратору в `/admin/`.
Изменения профиля влияют только на новые проверки; прежние отчёты сохраняют
свою версию правил. Результаты не являются официальным допуском к защите.

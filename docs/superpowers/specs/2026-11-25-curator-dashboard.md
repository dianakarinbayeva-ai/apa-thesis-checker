# Curator dashboard

The user approved a private curator dashboard with one button per programme group, registration/upload progress and latest-result statistics. The programme is 7М04120 — Мемлекеттік басқару, Executive MPA–2025, winter intake. EMPA-1 has 18 students and EMPA-2 has 19. Coordinators and curators are not students. Actual names are private runtime data and must never be committed or bundled.

Staff administrators can see all groups; a curator can see only groups assigned to their account by an administrator. Students cannot view curator pages, other students or registration codes. Registration codes bind new accounts to the correct private roster entry without publishing a name dropdown. Existing student accounts can join using their own group's code. Codes are available only to authorized curators, with no automatic messages sent.

Each roster entry counts once using its latest submission. Counts separate unregistered, registered, uploaded, not uploaded, processing, passed, revision required, insufficient evidence and technical failures. A completed check is a pass only with nonempty findings, zero violations and zero inconclusive findings. Empty or malformed reports are inconclusive. An unloaded roster has unknown counts, never a misleading zero. Curators can inspect reports for their own assigned groups, but cannot delete student documents.

The trilingual interface retains Academy branding. Repeated roster import is idempotent; conflicting replacements are rejected. Student names, registration codes, documents and databases remain under private data/. Windows archives and the public source download exclude these. Existing accounts, history and formatting checks remain compatible.
